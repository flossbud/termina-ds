No `UnsatisfiedLinkError` / `NoSuchMethod` / JNI binding failure anywhere in logcat.
All 6 renamed `Java_com_terminads_mm_MainActivity_*` symbols (attach/detachController,

confirmed controller + camera input work in-game — the exact code paths those 5
symbols serve.

## Note

Termina DS uses its own data root by design (install-alongside isolation), so the
user's existing 2S2H save did not appear initially — this is item 9 working, not a bug.
The stock 2S2H saves/ folder was manually copied into TerminaDS/saves/ to load the
user's progress. This is exactly the scenario Task 6 (one-time legacy import) automates.
